# QX policy icons

These 15 PNG files are 144×144 derivatives of icons from [Oasisic-Icons](https://github.com/Hawaiine/Oasisic-Icons), kept in this repository so Quantumult X can load the size it expects for policy icons.

The image files and the upstream MIT notice are included alongside this configuration. ChatGPT uses the upstream OpenAI icon because the source set does not have a separate ChatGPT image.

The images are referenced through raw GitHub URLs in each policy group's img-url parameter.
